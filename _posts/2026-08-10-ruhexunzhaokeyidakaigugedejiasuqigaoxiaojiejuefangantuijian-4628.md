<h4>Clash 节点配置指南</h4>
<p>Clash 是一款功能强大的代理客户端，支持多种代理协议，包括 SSR、V2Ray、Trojan 等。其核心在于使用 YAML 格式的配置文件来管理节点和规则。</p>
<ul>
<li><strong>获取订阅链接：</strong>通常，您需要从提供商那里获得 Clash 格式的订阅链接。这个链接会动态更新您的节点列表。</li>
<li><strong>在 Clash 客户端中添加订阅：</strong>打开您设备上的 Clash 客户端（例如，Windows 或 macOS 上的 Clash for Windows，Android 上的 Clash for Android，iOS 上的 Stash 或 Quantumult X 等），在设置或配置选项中找到“导入订阅”或“配置订阅”的入口，将订阅链接粘贴进去，并进行更新。</li>
<li><strong>节点选择与策略组：</strong>配置完成后，您可以查看节点列表，并根据“节点测速”结果选择最快的节点。Clash 还支持创建策略组，例如将访问谷歌设置为直连或使用特定节点，以优化访问体验。</li>
</ul>
<h4>Shadowrocket (小火箭) 使用技巧</h4>
<p>Shadowrocket 是 iOS 和 macOS 上非常受欢迎的代理客户端，以其简洁的界面和强大的功能著称。它同样支持多种协议。</p>
<ul>
<li><strong>订阅链接导入：</strong>与 Clash 类似，获取 Shadowrocket 支持的订阅链接（通常以 .txt 格式结尾，但也有其他格式）。在 Shadowrocket 应用中，点击右上角的“+”号，选择“类型”为“Subscribe”，然后将链接粘贴到 URL 字段，点击右上角的完成。</li>
<li><strong>手动添加节点：</strong>如果您有单个节点的详细信息（如服务器地址、端口、密码、加密方式等），也可以选择“类型”为“V2Ray”、“SSR”、“Trojan”等，然后手动输入各项信息。</li>
<li><strong>启用代理：</strong>添加节点后，在主界面选择您想要使用的节点，然后打开顶部的开关即可启用代理。</li>
</ul>
<h4>V2Ray 节点及其订阅管理</h4>
<p>V2Ray 是一个优秀的代理工具集，支持多种协议，包括 VMess、VLESS、Trojan 等。V2Ray 节点可以通过配置文件的形式进行导入，也可以通过 V2Ray 订阅链接进行批量管理。</p>

<li><strong>客户端导入：</strong>将订阅链接导入到支持 V2Ray 协议的客户端中。许多客户端都支持 V2Ray 订阅的直接导入，例如 V2RayNG (Android)、nekoray (Windows/macOS) 等。</li>
<li><strong>配置文件的本地化：</strong>对于更高级的用户，也可以将 V2Ray 的配置信息以 JSON 文件的形式保存，然后直接加载到 V2Ray 核心程序中运行。</li>
